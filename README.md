# StarCraft 1 상성 훈련소

Brood War의 피해 타입과 유닛 크기 상성을 연습하는 정적 웹앱입니다.

## 파일 구조

- `index.html` — 화면 구조와 CSS/JS 파일 연결
- `css/styles.css` — 전체 UI 스타일
- `css/quiz.css` — 퀴즈 대진/범위 선택 UI 스타일
- `css/game.css` — 타임어택/스코어어택 UI 스타일
- `js/data.js` — 피해 타입, 유닛 크기, 종족, 유닛 데이터
- `js/ui.js` — 공통 DOM/배지 표시 유틸리티
- `js/knowledge.js` — 종족별 유닛 공격 형태/크기 문제 생성 및 해설
- `js/game.js` — 타이머, 30문제/60초 게임 진행, 최고 기록 저장
- `js/quiz.js` — 퀴즈 모드 전환, 대진/범위 필터, 채점, 오답 복습, 게임 모드 연결
- `js/catalog.js` — 유닛 도감 렌더링, 검색, 종족 필터
- `js/app.js` — 각 기능 초기화만 담당

## 어디를 수정하면 되나요?

- 유닛 크기/공격 타입/유닛 추가: `js/data.js`
- 유닛 지식 문제 생성/보기/해설: `js/knowledge.js`
- 퀴즈 모드/대진 범위/정답 처리: `js/quiz.js`
- 타임어택/스코어어택 규칙과 최고 기록: `js/game.js`
- 퀴즈 선택 UI 디자인: `css/quiz.css`
- 게임 HUD/플레이 방식 디자인: `css/game.css`
- 유닛 검색/필터/도감 카드: `js/catalog.js`
- 전체 색상/레이아웃/반응형 디자인: `css/styles.css`
- 화면의 고정 문구나 섹션: `index.html`

## 유닛 적용 퀴즈 대진

`TvT`, `TvP`, `TvZ`, `PvP`, `PvZ`, `ZvZ` 중 하나를 선택할 수 있습니다. 서로 다른 종족 대진은 양방향 공격 문제가 섞여 나옵니다. 문제를 풀기 전에는 공격 피해 타입과 방어 유닛 크기를 표시하지 않고, 채점 후 해설에서 공개합니다.

## 유닛 지식 퀴즈

테란, 프로토스, 저그 중 하나를 선택해 해당 종족 유닛만 연습할 수 있습니다. 문제 종류는 `섞어서`, `공격 형태`, `유닛 크기` 중에서 선택합니다.

- 공격 형태: 일반형, 진동형, 폭발형, 공격 없음 중에서 선택
- 지상/대공 공격 형태가 다른 유닛은 어떤 공격을 묻는지 문제에 표시
- 기본 무기 공격이 없는 유닛도 `공격 없음` 문제로 출제
- 유닛 크기: 소형, 중형, 대형 중에서 선택

## 게임 방식

각 퀴즈 모드와 현재 선택한 세부 범위에서 `연습`, `타임어택`, `스코어어택`을 선택할 수 있습니다.

- 연습: 기존 방식. 정답 후 해설을 확인하고 오답 복습 가능
- 타임어택: 30문제 고정. 30문제를 모두 풀면 종료
- 스코어어택: 60초 고정. 제한 시간 동안 맞힌 정답 수가 점수

최고 기록은 브라우저 `localStorage`에 간단히 저장합니다. 기록은 현재 퀴즈 범위별로 분리됩니다. 예를 들어 `TvT`와 `TvP`, 또는 `테란 공격 형태`와 `저그 유닛 크기`는 각각 별도 기록을 가집니다.

- 타임어택 기록: 정답 수가 높은 기록 우선, 정답 수가 같으면 더 빠른 시간 우선
- 스코어어택 기록: 60초 동안 맞힌 최고 정답 수

`기록 초기화`를 누르면 일반 퀴즈 통계, 오답 기록, 타임어택/스코어어택 최고 기록을 함께 초기화합니다.

빌드 과정은 없습니다. 정적 웹 서버나 GitHub Pages에서 `index.html`을 열면 동작합니다. 정적 자산을 수정할 때는 브라우저 캐시 문제를 막기 위해 `index.html`의 `?v=` 버전도 함께 갱신합니다.
